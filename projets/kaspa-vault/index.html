How a transaction is made

No wallet can spend a custom covenant, so the project ships its own tool chain. Every transaction is executed locally in the same script engine as a Kaspa node before it is broadcast.

1

Contract

vault.sil, compiled by the SilverScript v1.0 compiler.

2

Setup

vault_setup (Rust) generates keys, fills the constructor, and derives the P2SH address.

3

Build & sign

vault_tx (Rust) signs with Schnorr and computes the post-Toccata mass.

4

Local check

Runs in TxScriptEngine. A failing script never leaves the machine.

5

Broadcast

vault_net.py fetches UTXOs, sets the fee, and submits to the REST API.

Security decisions

An audit of the time-lock design found issues and fixed them, and the limits that remain are stated plainly.

The "drip" attack Fixed

Relative locks reset on every spend. A thief with the owner key could withdraw a little every day and keep the vault "active" forever, which would block recovery. The absolute-deadline path cannot be pushed back, and a test proves recovery still works on a freshly reset UTXO.

Fee that would never relay Fixed

The first version hard-coded a 1,000-sompi fee. The network minimum is 100 sompi per gram, and a withdraw weighs about 2,400 grams, so every withdraw would have been rejected. Fees are now free but capped at 0.1 tKAS, which bounds what a thief can burn.

Language constraint Handled

In SilverScript v1.0, a time lock must be its own require(TxVar >= x) statement and cannot be OR-ed. The "inactivity OR deadline" rule is therefore expressed as two entrypoints, and the OR happens in the choice of selector.

Known limits Accepted

A patient thief can still take 100 tKAS a day or sweep after 3 days, so fast detection matters. An off-chain watcher raises an alert within 60 seconds of any spend. Delays are counted in DAA score (≈ 10/s), so a future block-rate hard fork would shorten them and require migrating to a new vault.

The core of the contract

The withdraw path from vault.sil. Error messages in require cost nothing in bytecode.

entry withdraw(sig ownerSig, int amount) {
    require(checkSig(ownerSig, owner), "invalid owner signature");
    require(this.ageDaa >= withdrawCooldown, "cooldown not elapsed");

    require(amount > 0, "invalid amount");
    require(amount <= maxWithdrawAmount, "amount above cap");

    int inputValue = tx.inputs[this.activeInputIndex].value;
    require(inputValue > amount, "insufficient balance");
    require(tx.outputs[0].value == amount, "wrong output amount");

    // Everything except `amount` and at most MAX_MINER_FEE goes back to the vault.
    int minChangeValue = inputValue - amount - MAX_MINER_FEE;
    if (minChangeValue > 0) {
        byte[] vaultScriptPubKey = tx.inputs[this.activeInputIndex].scriptPubKey;
        require(tx.outputs[1].scriptPubKey == vaultScriptPubKey, "change must return to the vault");
        require(tx.outputs[1].value >= minChangeValue, "fee above the allowed maximum");
    }
}
